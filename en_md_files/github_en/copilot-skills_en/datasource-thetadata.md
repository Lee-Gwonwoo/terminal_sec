# ThetaData / ThetaTerminal (skill)

## EN

### When to use
- When a workflow needs ThetaData and requires running the Java ThetaTerminal locally.
- When troubleshooting data access that depends on ThetaTerminal being started and `thetadata/credit.txt` being present.

- **ThetaData / ThetaTerminal**
  - Start the Java ThetaTerminal via `thetadata/run_theta_terminal.ps1` and keep `thetadata/credit.txt` next to the script.
