# Trading Statistics — 갭 이벤트 사후 수익률 통계

> 상태: **설계 확정 전**. z-score 기준이 확정되지 않았고, 착수 전 해결해야 할 데이터 블로커가 있다.
> 이 문서는 범위와 확인된 레포 상태만 고정한다. 코드 수정은 하지 않는다.
> z-score 결정은 [zscore_criteria.md](zscore_criteria.md) 참고.

## 1. 목표

갭 상승 이벤트 이후 주가 흐름의 raw 분포를 통계로 남긴다. 두 가지 이벤트 정의를 각각 측정한다.

- **Case 1 — 어닝 이벤트**: 실적 발표에 대한 첫 반응일의 갭이 평소보다 컸을 때, 그 이후 흐름
- **Case 2 — 비어닝 뉴스 이벤트**: 어닝이 아닌 이슈로 갭 상승했을 때, 그 이후 흐름

두 케이스 모두 결론(평균)만이 아니라 **raw 데이터 분포를 점도표로** 볼 수 있어야 한다.

## 2. 용어 정의

- **1day** — 주가가 이벤트에 처음 반응하는 거래일
  - 어닝 `BMO`(pre) → 발표 당일
  - 어닝 `AMC`(after) → 다음 거래일
  - Case 2 → 갭이 발생한 당일
- **2day** — 1day의 다음 거래일
- **gap%** — `(Open[t] − Close[t−1]) / Close[t−1] × 100`
- **o2c%** — `(Close[t] − Open[t]) / Open[t] × 100`
- **turnover** — `Close × Volume`

> 1day/2day는 **캘린더 날짜가 아니라 거래일 인덱스**로 이동한다. 금요일 AMC → 월요일, 휴장일 건너뜀이 자동으로 처리되어야 한다.

## 3. 측정 항목

### Case 1 — 어닝

| ID | 조건 | 측정 |
|---|---|---|
| 1-1-a | 1day gap z ≥ 기준 | 1day o2c% |
| 1-1-b | 위 + 1day o2c% < 0 | 2day o2c% |
| 1-1-c | 위 + 1day o2c% > 0 | 2day o2c% |
| 1-2 | 위 이벤트 전체 | 2day 종가 → +1개월 / +2개월 종가 등락률 (점도표) |

### Case 2 — 비어닝 뉴스

| ID | 조건 | 측정 |
|---|---|---|
| 2-1-a | gap z ≥ 기준 **AND** 당일 뉴스 존재 | 당일 o2c% |
| 2-1-b | 위 + 당일 o2c% > 0 | 2day o2c% |
| 2-1-c | 위 + 당일 o2c% < 0 | 2day o2c% |
| 2-2 | 위 이벤트 전체 | 당일 종가 → +1개월 / +2개월 종가 등락률 (점도표) |

**뉴스 판정 (텍스트 검증 없이 존재 여부만)** — 비용 절감을 위해 LLM 검증을 하지 않고, 해당 일자에 아래 중 하나라도 있으면 "평소와 다른 이슈"로 간주한다.

- `news_items.source_type = 'fmp_press_release'`
- `news_items.source_type = 'press_release'` (Finnhub)
- `sec_filings.form_type = '8-K'`

필터 순서는 **갭 먼저 → 뉴스 나중**이다. (갭이 훨씬 희소해서 조인 비용이 작다.)

## 4. 공통 필터 / 분류축

- 시가총액 ≥ **$300M**
- turnover ≥ **$100M**
- 분류축: **industry**, **market cap**, **turnover** — 모든 케이스에서 raw 행에 함께 남긴다

## 6. 착수 전 해결해야 할 블로커

### B1. (치명적) OHLC 분할·수정주가 정합성 깨짐
정제 없이 계산한 gap 분포에서 **첨도 934,088**, 최대 갭 **+21억%** 가 나온다.

- `|gap| > 20%` 행이 1,826개
- **2021-12-02 하루에만 24건이 몰려 있고**, 대상이 ORLY(−93%), MSTR(−90%), PANW(−83%), NOW(−80.0007%), FTNT(−80.0007%), TSCO(−80.0%), COO(−75.02%) 등이다
- 이 종목들은 그날 분할하지 않았고, 비율이 정확히 5:1·4:1로 떨어진다 → **분할 실행이 아니라 수정주가 vintage가 섞인 인제스트 사고**
- `TOPCF 2026-01-13`은 `Open = Close = 447,466,144` (명백한 오염 행)

→ 이 상태에서 계산한 gap z-score는 무의미하다. 오염 행 하나가 이후 60일 창의 σ를 통째로 왜곡하므로 영향 범위는 1,826행보다 훨씬 넓다. **정제 규칙 확정이 z 기준 확정보다 먼저다.**

### B2. Case 2의 뉴스 데이터 기간이 몇 달뿐
사용자가 지정한 3개 소스 중 2개가 2026년 데이터만 있다 (위 표). 그대로 쓰면 Case 2 관측 구간이 약 5개월인데, +2개월 선행 수익률을 요구하므로 **완결 관측치가 거의 남지 않는다.**

→ Case 2는 **Finnhub `press_release`(2020~)를 주 소스**로, FMP PR/8-K는 2026년 한정 보강으로 다루는 것을 권고. 결정 필요.

### B3. 가격 데이터가 오늘 기준 약 2.5개월 낡음
OHLC 종료일 `2026-05-05`, 오늘 `2026-07-19`. 약 `2026-03-05` 이후 이벤트는 +2개월 수익률을 만들 수 없다.
→ 실행 전 OHLC 갱신 필요. 미완결 선행 구간은 **행 제외**로 처리하고 0으로 채우지 않는다.

### B4. 시가총액 ≥ $300M 필터의 look-ahead / 생존 편향
`company_profiles.market_cap`은 **현재 스냅샷**(7,349행 / 2,290 증권)이고 과거 시계열이 없다. 이걸 2015년 이벤트에 적용하면 (a) 미래 정보로 과거를 필터링하고 (b) 상장폐지 종목이 통째로 빠진다.

→ `outstanding_shares × Close`로 과거 시총을 역산하는 방식을 권고(현재 주식수를 쓰므로 완벽하진 않지만 훨씬 낫다). 추가로 OHLC 유니버스 자체가 **watchlist 3,223종목**이라 이미 생존 편향이 있다는 점을 결과 문서에 명시한다.

### B5. turnover 필터를 이벤트 당일 기준으로 걸면 결과에 조건을 거는 셈
이벤트 당일 turnover는 **이벤트 때문에** 부풀어 있다. 당일 turnover ≥ $100M로 거르면 "주목받은 이벤트"만 선택되어 사후 수익률이 낙관적으로 편향된다.

→ **직전 20거래일 중앙값 turnover ≥ $100M**로 거는 것을 권고. 당일 기준도 병기 가능.

### B6. Case 2가 Case 1을 상당 부분 다시 측정하게 됨
어닝 릴리스 자체가 press release이자 8-K(Item 2.02)다. Case 2에서 어닝일을 빼지 않으면 두 케이스가 크게 겹친다.

→ Case 2는 **어닝 윈도우(1day·2day)를 명시적으로 제외**해야 "비어닝 이슈"라는 정의가 성립한다. 스펙에 빠져 있던 조건.

## 7. 확인 필요한 스펙 모호점

- **Q1. 갭 상승만 볼 것인가?** 스펙은 "갭 상승"만 언급한다. 어닝은 큰 하락 갭도 만드는데, 상승만 보면 대조군이 없어 결과 해석이 어렵다. → 하락 갭을 대칭 버킷으로 함께 남기는 것을 권고(비용이 거의 없다).
- **Q2. `time_of_day`가 NULL/Unknown인 어닝 15,462건(약 26%) 처리?** → 제외 권고. 1day 정의가 성립하지 않는다.
- **Q3. "+1개월 / +2개월"은 거래일 기준(21일/42일)인가, 캘린더 기준인가?** → 거래일 21/42 권고.
- **Q4. 점도표 출력 형태** — 정적 이미지(PNG)인가, 터미널 UI 윈도우인가? 현재는 "이미지로 볼 수 있게"로만 되어 있다.
